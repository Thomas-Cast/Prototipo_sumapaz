# Prototipo Sumapaz

Monitoreo recursivo para la rentabilidad agricola y el relevo generacional
en Fusagasuga, Cundinamarca.

## Que es

Prototipo funcional en Python 3 que aplica funciones recursivas para monitorear
tres variables clave del pequeno productor agricola:

1. Costo acumulado de la finca (arbol Finca -> Lote -> Cultivo -> Insumo).
2. Meses de supervivencia financiera (serie temporal).
3. Indice de vulnerabilidad sucesoral (arbol genealogico).

Ademas, calcula el promedio de pH del suelo y compara precios entre almacenes
agricolas usando ciclos tradicionales.
